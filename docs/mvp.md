# План MVP

## 1. Базовая структура публичной части

Результат: настроены основные публичные страницы и маршруты для главной страницы, каталога и страницы о бренде.

## 2. Категории

Результат: создана сущность Category, добавлены публичные страницы категорий и связь категорий с украшениями.

## 3. Украшения

Результат: создана сущность Product, добавлены поля для названия, цены, описания, материалов, длины и статуса наличия.

## 4. Фотографии через Active Storage

Результат: товары могут иметь несколько фотографий, изображения отображаются в каталоге и на странице украшения.

## 5. Заявки покупателей

Результат: покупатель может отправить заявку на выбранное украшение, указав имя, контакт и необязательный комментарий.

## 6. Авторизация администратора

Результат: администратор может входить в закрытую часть сайта через has_secure_password.

## 7. Административная часть

Результат: вручную создана административная часть для управления категориями, украшениями, фотографиями и заявками.

## 8. Валидации и тесты

Результат: добавлены базовые валидации моделей и тесты для ключевых сценариев MVP.

## 9. Подготовка к публикации

Результат: проверены настройки окружения, секреты, база данных, хранение файлов и базовый сценарий работы приложения перед публикацией.
